# Portfolio Website - Ravshanov Yuxanno

Professional portfolio website built with React, Vite, and TailwindCSS.

## Features

- Modern, responsive design
- Smooth animations and transitions
- SEO optimized
- Mobile-friendly
- Fast loading times

## Technologies Used

- React
- Vite
- TailwindCSS
- Framer Motion
- React Icons

## Setup Instructions

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## SEO Features

This portfolio is optimized for search engines with:

- Proper meta tags
- Structured data (JSON-LD)
- robots.txt
- sitemap.xml
- Canonical URLs
- Open Graph tags for social sharing

## Deployment

For best SEO results, deploy to a platform that supports static site hosting:

- Vercel
- Netlify
- GitHub Pages
- Firebase Hosting

After deployment, submit your sitemap to Google Search Console for faster indexing.
